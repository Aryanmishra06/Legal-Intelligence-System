# Legal-Intelligence-System
An AI-powered legal analytics and case search platform developed using Python, Flask, and Machine Learning.
This project helps users perform smart legal case searches, analyze court datasets, and predict possible case outcomes using ML models.

🚀 Features
🔍 Smart Legal Case Search using TF-IDF + Cosine Similarity
📊 Interactive Dashboard for Legal Analytics
🤖 Machine Learning-based Outcome Prediction
⚡ Live Search Functionality
📂 Court Dataset Handling & Analysis
📈 Case Type and Category Statistics
🧠 Intelligent Recommendation System for Legal Records

🛠️ Technologies Used
Python
Flask
Pandas
Scikit-learn
HTML/CSS/JavaScript
Machine Learning
TF-IDF Vectorization
Random Forest Classifier

Developed an intelligent legal information retrieval system.
